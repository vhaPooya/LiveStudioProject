LiveStudio Stage 7 — Audio Mixer

New navigation item: «میکسر حرفه‌ای صدا»
Route: /audio-mixer

The audio mixer provides a microphone meter, input gain, high-pass filtering,
3-band EQ, compressor controls, and browser capture options for noise suppression,
echo cancellation, and auto gain control. Saved settings are applied to the audio
track in Creator Studio local recordings.

Note: the live LiveKit microphone path is not yet processed by this mixer.
See AUDIO_MIXER_STAGE7.md for scope and validation details.
